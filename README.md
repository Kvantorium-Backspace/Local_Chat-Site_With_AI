## 🧾 Описание

**Быстроразворачиваемый локальный чат-сайт с нейросетями для учеников Кванториума**
- *Развернут на сервере Кванториума и локально работает для учеников*
- *Ученики могут использовать код проекта для практики в frontend разработке на react*
- *Состоит из контейнера с моделями из ollama, backend на python (fast api) и frontend (react)*

## 🚀 Как запустить?

1. **Установите зависимости:**  
   `docker`, `npm`, `ollama`, `git`, `python`

2. **Клонирование репозитория:**  
   ```bash
   git clone https://github.com/Kvantorium-Backspace/Kvantorium_Local_LLM.git
   cd Kvantorium_Local_LLM
   ```

3. **Выбор и настройка модели**

   - *Выбери модели на сайте `https://ollama.com/library`*  

   - *Создай файл `./ollama/ModelsConfig.jsx` по примеру `./ollama/ModelsConfig.jsx.example`*

   *Если модель облачная, необходимо авторизоваться:*
   ```bash
   ollama login
   ```

4. **Настрйока .env файлов**

   *Создай `./.env` по примеру `./.env.example`*

   *Создай `./frontend/.env` по примеру `./frontend/.env.example`*


5. **Запусти проект**

   *`./run.sh` - для linux*

6. **Установка выбранных моделей**  
   *Если модель облачная, ее скачивать не нужно*
   ```bash
   docker compose exec ollama ollama pull (название модели)
   ```

7. **Настройка системного промпта**  

   *Ты можешь изменить системный промпт. Для этого напиши в файл `./ollama/system-prompt.txt` желаемый текст*

8. **Использование**

   *Теперь сайт-чат с установленными локальными и облачными LLM доступен по ip `http://127.0.0.1:5173/` в локальной сети*

## 💬 Использование

### Интерфейс

1. **Выбор модели** — кнопки в верхней панели (`Быстрая` / `Думающая`)
2. **Написание сообщения** — поле ввода внизу
3. **Отправка** — кнопка стрелка ↑ или Enter
4. **Остановка ответа** — кнопка квадрат ■ 
5. **Очистка истории** — кнопка "Очистить историю" (с подтверждением)

### Для разработки своего frontend

**В `./frontend/src/api/index.jsx` расписаны хуки и как их использовать**

*Пример:*

```javascript
import { useChatClient } from './api'
import { MODELS } from './api/ModelsConfig'

export default function MyApp() {
  const { messages, loading, activeModel, setActiveModel, sendMessage, stopGeneration, clearHistory } = useChatClient()

  const handleSend = async () => {
    await sendMessage('Привет!')
  }

  return (
    <div>
      {messages.map((msg, i) => (
        <div key={i}>{msg.role}: {msg.content}</div>
      ))}
      <button onClick={handleSend} disabled={loading}>Отправить</button>
      {loading && <button onClick={stopGeneration}>Остановить</button>}
    </div>
  )
}
```

## 🎯 Цели

1. **🟢 Идеальный результат**
	1. Проект разворачивается и запускается одной командой
	2. Указывает все возможные ошибки и этапы, на которых они произошли
	3. Есть возможность выбрать свою LLM

	9. Автоустановка зависимостей
	10. Можно установить свои ссылки для backend и ollama
	11. Есть несколько функций для общение с backend (без истории, с историей и стриминг с историей)

	2. Сайт легко разворачивается
