# 🧠 Локальная нейросеть Кванториума

> **Основана на** `ollama`
> **Разработано командой** `Backspace`

**Ты можешь использовать этот проект и развернуть локальную нейросеть (в том числе свою) у себя на пк/сервере**
**Дизайн сайта можешь спокойно изменить**

---

## 🚀 Как запустить?

1. **Установите зависимости:**  
   `docker`, `npm`, `ollama`, `git`

2. **Склонируйте репозиторий:**  
   ```bash
   git clone https://github.com/Kvantorium-Backspace/Kvantorium_Local_LLM.git
   ```

3. **Выбери модели на сайте `https://ollama.com/library` (без тега cloude)**  

   *Впиши в файл `./ollama/ModelsConfig.tsx` данные об выбранной модели:*
   ```
      export const MODELS = {
         (ключ модели внутри проекта): {
            id: "(название модели)",
            label: "(что будет отображаться в селлекторе выбора)",
            description: "(описание модели)",
            thinkMode: "(false/true - в зависимости от того, хочешь ли включить режим размышления)",
         },
      }
   ```
   *Ключ менять не обязательно. При изменении или добавлении 3+ модели: измени так же ключи в `./frontend/App.jsx` у model-switcher*

4. **Запусти проект**

   **`./run.bat` - для windows**
   
   **`./run.sh` - для linux**

5. **Установи выбранные модели**  
   ```bash
   docker compose exec ollama ollama pull (название модели)
   ```

6. **Теперь сайт с установленными локальными LLM доступен по ip твоего пк в локальной сети**

   *чтобы добавить порт, измени в ./docker-compose.yml `80:80` на `80:(желаемый порт)`*
